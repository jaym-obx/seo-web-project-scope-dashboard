    Formula editor

    Every task carries its own base hours, increment, and block rule. Each phase closes with an Implementation row. Enter hours there and they are added to every package it is checked for, with no scaling. Implementation add-ons ship unchecked for the Included by Default tier and can be added to it when needed. Default hrs is a fixed rate for the Included by Default tier only. A task carrying one always bills that figure there, never scaled. Leave it blank to use base hours.

    Task Base hrs Default hrs + hrs/block Cap Scaling rule Blocks Def Ess Pro Ent Points Cost
    Blocks round up, so 1 to 25 pages is one block and 26 is two. Base hours cover the first block, each block after that adds the increment, and the cap is the ceiling. A count of zero means zero blocks and zero cost. Edits save in this browser only and do not write back to the Google Sheet. When the published model is updated, local edits are cleared so everyone sees the same figures.
